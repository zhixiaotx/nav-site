# 🚀 我的导航站

> 一个汇聚 **55 个精选分类** 的纯静态导航站。左侧挑分类，右侧看链接；顶部搜索框一键检索。

## 🧭 三步上手

1. 点击左侧 **分类栏** 挑选感兴趣的分类
2. 在右侧查看该分类下的「站点名称 · 链接 · 介绍」表格
3. 用顶部 **搜索框** 直接搜「分类名 / 站点名」

> 💡 手机端：点左上角 ☰ 展开分类栏。
